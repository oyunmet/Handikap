# Bot GLB modelleri

Gece Nöbetçisi düello modeli bu klasöre `gece-nobetcisi.glb` adıyla eklenir.
Önerilen sınırlar: 50.000 üçgenden az, en büyük dokular 2.048 px veya daha küçük.

Ölçek, model yönü, pelerin/vurgu malzeme adları ve animasyon klip eşlemesi
`src/shafak/world/opponent-model-config.ts` içindedir. Önerilen klip adları:
`Idle`, `Run`, `Attack1`, `Block`, `Dodge`, `HitReaction`, `Death`, `Victory`.
Dosya henüz eklenmemişse oyun mevcut low-poly karakteri gösterir.
