name: Royal Match specials
description: User requirements for special-tile creation, swaps, and activation effects.
---

Use recognizable special pieces for the match shape: a four-tile line creates a directional rocket, a five-or-longer line creates the color-clearing lightball, a 2×2 match creates a propeller, and a crossing match creates TNT. Swapping a lightball with a normal adjacent tile clears every tile of the partner's color. Special actions should have visible, distinct effects.

**Why:** The user shared Royal Match reference screenshots and requested these match outcomes, icons, full-color lightball clearing, and activation effects.

**How to apply:** When changing special-tile logic or animation, verify the match shape, the adjacent-swap behavior, and that no targets are omitted on a crowded board.
