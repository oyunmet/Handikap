name: Direct code changes
description: The user's project-specific preference for continuing implementation without opening project tasks.
---

When the user asks to continue implementation, make the code changes directly rather than creating project tasks, unless the user explicitly asks for tasks.

**Why:** the user has repeatedly asked for direct code changes without a task.

**How to apply:** use this rule for implementation requests in this project; it does not authorize deployment, Git pushes, or other external actions.
